# THE WHOLE HOUSE

Lucent sees. Corti measures. OpenSmell sniffs. Skin sits. Porch hears the words. Memory keeps the building.

One body. No login. No Better Auth. No invented scene, note, gas, or pose.

```bash
npm install
npm run dev
```

Opens on `http://127.0.0.1:8080`.

| Path | Organ |
|---|---|
| `/` | The body |
| `/lucent` `/see` | Sight |
| `/hear` | Corti |
| `/say` | Porch |
| `/smell` | OpenSmell |
| `/touch` | Skin |
| `/remember` | Memory |
| `/sound` | Christman-Sound ingest |

If a preview frame cannot hold a camera, a microphone, a serial nose, or a gyroscope, open the organ in its own window. That window is the sense.

Porch is the only nerve that may leave the porch for words, and it has to say so.

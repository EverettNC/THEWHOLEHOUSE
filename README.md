# THE WHOLE HOUSE

Lucent sees. Corti measures. OpenSmell sniffs. Skin sits. Porch hears the words. Memory keeps the building.

One body. No login. No Better Auth. No invented scene, note, gas, or pose.

```bash
npm install
npm run dev
```

Opens on **9785**. That is the house.

```
http://127.0.0.1:9785
```

**8080 is the lab. Off limits.** The house will not sit on it. `PORT=… npm run dev` if you need another door.
